২. ধাপে ধাপে পূর্ণাঙ্গ লিখিত সমাধান

Step 01
dydx=(1+cos⁡x)ddx(1+sin⁡x)−(1+sin⁡x)ddx(1+cos⁡x)(1+cos⁡x)2\frac{dy}{dx} = \frac{(1+\cos x)\frac{d}{dx}(1+\sin x) - (1+\sin x)\frac{d}{dx}(1+\cos x)}{(1+\cos x)^2}dxdy​=(1+cosx)2(1+cosx)dxd​(1+sinx)−(1+sinx)dxd​(1+cosx)​
ব্যাখ্যা: ভাগফলের অন্তরীকরণ সূত্র অনুযায়ী সাজানো হলো।
Step 02
dydx=(1+cos⁡x)(cos⁡x)−(1+sin⁡x)(−sin⁡x)(1+cos⁡x)2\frac{dy}{dx} = \frac{(1+\cos x)(\cos x) - (1+\sin x)(-\sin x)}{(1+\cos x)^2}dxdy​=(1+cosx)2(1+cosx)(cosx)−(1+sinx)(−sinx)​
ব্যাখ্যা: ডেরিভেটিভ মানগুলো যথাস্থানে বসানো হলো।
Step 03
dydx=(cos⁡x+cos⁡2x)+(sin⁡x+sin⁡2x)(1+cos⁡x)2\frac{dy}{dx} = \frac{(\cos x + \cos^2 x) + (\sin x + \sin^2 x)}{(1+\cos x)^2}dxdy​=(1+cosx)2(cosx+cos2x)+(sinx+sin2x)​
ব্যাখ্যা: ব্র্যাকেট তুলে গুণ সম্পন্ন করা হলো।
Step 04
dydx=cos⁡x+sin⁡x+(cos⁡2x+sin⁡2x)(1+cos⁡x)2=cos⁡x+sin⁡x+1(1+cos⁡x)2\frac{dy}{dx} = \frac{\cos x + \sin x + (\cos^2 x + \sin^2 x)}{(1+\cos x)^2} = \frac{\cos x + \sin x + 1}{(1+\cos x)^2}dxdy​=(1+cosx)2cosx+sinx+(cos2x+sin2x)​=(1+cosx)2cosx+sinx+1​
ব্যাখ্যা: ত্রিকোণমিতিক অভেদ cos⁡2x+sin⁡2x=1\cos^2 x + \sin^2 x = 1cos2x+sin2x=1 প্রয়োগ করে সংক্ষেপ করা হলো।
FINAL ANSWER
dydx=cos⁡x+sin⁡x+1(1+cos⁡x)2\mathbf{\frac{dy}{dx} = \frac{\cos x + \sin x + 1}{(1+\cos x)^2}}dxdy​=(1+cosx)2cosx+sinx+1​
